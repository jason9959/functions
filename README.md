# 통합 포트폴리오 대시보드

기존 `app_gpt.py`의 1~5번 기능을 유지하고 6~10번을 기능별 모듈로 통합한 Streamlit 프로젝트입니다.

## 메뉴
1. 상대 수익률 비교
2. 주기별 수익률 분석
3. 포트폴리오 백테스트
4. 정규분포 몬테카를로
5. Bootstrap 몬테카를로
6. 인플레이션 나침반
7. 달러 환율 나침반
8. 기업 재무 대시보드
9. 이동평균 투자전략 백테스트
10. 라오어 무한매수법 백테스트 (V2.2)

## 공통 UX
- 조건 화면 하단: 왼쪽 `뒤로`, 오른쪽 `실행`
- 결과 화면 하단: 왼쪽 `조건으로 돌아가기`, 오른쪽 `결과 저장`
- 결과 화면에서 조건으로 돌아가도 입력값을 유지
- `↺ 조건 초기화`를 눌렀을 때만 해당 기능의 조건/결과를 초기화
- 기능별 session state에 `f06_`~`f10_` 접두사를 사용해 충돌 방지

## 실행
```bash
pip install -r requirements.txt
streamlit run app.py
```

## 8번 기업 재무 대시보드
기존과 동일하게 Streamlit Secrets의 다음 키를 사용합니다.
```toml
DART_API_KEY = "..."
SEC_USER_AGENT = "Your Name your-email@example.com"
```
기존 배포 앱에 같은 키가 이미 설정되어 있다면 변경할 필요가 없습니다.

## 6번 인플레이션 나침반
기본적으로 Yahoo Finance/FRED에서 공개 데이터를 자동 조회합니다. 재현 가능한 고정 데이터가 필요하면:
```bash
python features/feature06_inflation/download_data.py
```
로 `features/feature06_inflation/data/`를 만들 수 있으며, 앱은 로컬 데이터가 존재하면 이를 우선 사용합니다.

## 10번 라오어 무한매수법
현재 V2.2를 먼저 구현했습니다.
- LOC 매수: 종가가 한도 이하일 때 종가 체결
- LOC 매도: 종가가 한도 이상일 때 종가 체결
- +10% 지정가 매도: 일중 High가 목표 이상일 때 목표가 체결
- 별%: 40분할 기준 `10 - T/2`, 다른 분할 수에도 비례 일반화
- 전반전: 평단/별%에 각각 0.5회분 LOC
- 후반전: 별%에 1회분 LOC
- 매도: 보유 1/4 별% LOC + 3/4 목표수익 지정가
- 쿼터손절은 공개 설명의 일봉 OHLC 재현 한계 때문에 별도 `근사 구현` 옵션으로 분리

T값은 백테스트의 일관성을 위해 `현재 보유분 원가 / 1회 매수 시도액`으로 계산합니다. 부분매도 시 원가도 비례 감소합니다. 이 가정은 화면에 명시되어 있습니다.
